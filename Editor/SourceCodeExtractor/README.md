# 源码提取工具

Unity 菜单入口：`Cowart > 项目开发工具 > 源码导出`

## 功能

- 从指定目录递归提取源码文件。
- 支持将所有源码合并为一个 UTF-8 无 BOM 文本文件。
- 支持按原目录结构复制源码，复制模式会额外生成文件清单。
- 可配置文件扩展名、排除目录名以及是否包含 `.meta` 文件。
- 可选择包含 Unity 当前已注册的全部 `Packages` 包源码，默认关闭。
- 每次输出使用时间戳命名，不覆盖已有提取结果。
- 只读取源文件，不会修改或删除源文件。

默认源码目录是项目的 `Assets` 目录，默认输出目录是项目根目录下的 `SourceCodeExports`。
